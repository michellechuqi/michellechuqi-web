## Map and symbology description
This is a map of all the main entrances of buildings on UBC. The symbology emphasises the accessibility of entrances: 
* ACCESSIBLE: 1 means that a building entrance is accessible. It is coloured green when all entrances are shown and magenta when accessible entrances are highlighted.
* ACCESSIBLE: 0 means that a building entrance is not accessible. It is coloured red when all entrances are shown and magenta when all not accessible entrances are highlighted.

The hover popups display the name of the building.

## Data source
Data for the main entrances of UBC buildings was taken from UBCGeodata.
