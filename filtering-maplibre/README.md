## Notes on how to use map
When Show All Crashes is clicked, blue dots represent road crashes with no fatalities. Red dots represent road crashes with fatalities.

Clicking on any specific road crash will show the number of fatalities and the exact coordinates of the crash.

For the Highlight Fatality Status text box, entering 0 will highlight all road crashes with no fatalities. Entering 1 will highlight all road crashes with 1 or more fatalities. The text box is only configured for an entry of 0 or 1.

## Data attribution
Data taken from the Department for Infrastructure and Transport in the South Australian Government Data Directory. The data directory maintains a dataset called "Road Crash Locations in SA". This map uses a .geojson file called "Road Crashes 2021-2025 (geojson)" in that dataset.
